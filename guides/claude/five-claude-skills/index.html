A note before you begin

Five Claude Skills Worth Adding

This is the companion to the “five powerful Claude skills” video. Pick the skill that fits your next task, follow its setup instructions, and try the example prompt. You do not need to install everything at once.

The main walkthrough uses Claude Code on your computer. The commands below go into your computer’s terminal; prompts beginning with a slash go inside Claude Code. A separate chapter covers Claude’s web interface. These are community-created skills. Downloading a skill and paying for AI usage are separate things.

Chapter 021 min read

Set up your workspace

  1. Install and sign in to Claude Code.
  2. Install a recent Node.js LTS release that meets the installer’s requirements. Anatomy’s documentation specifies Node 22.20 or newer for the skills CLI version it describes.
  3. Create a folder for your work, then open that folder in Claude Code.
  4. Open your computer’s terminal and run the install command for your chosen skill.
  5. Open a fresh Claude Code session in your work folder and run its starter prompt.

Check that Node and npm are available:

node --version
npm --version

The installer below is the Vercel skills CLI. In these examples, -g makes the skill available across your projects and -a claude-code selects Claude Code. Omit -g if you prefer a project-only installation. Follow any installer prompts.

Keep your business files or learning folder separate from the skill’s installation folder. The former holds your work; the latter holds instructions and supporting resources.

Chapter 032 min read

Chief of Staff: clarify a business decision

Best for: “We have several options. Help me understand the tradeoffs and next steps.”

The selected version routes questions to executive advisor roles and synthesizes their perspectives. It uses companion skills for company context, meeting coordination, and decision records. Install its C-level pack so those references are available:

npx skills add https://github.com/alirezarezvani/claude-skills/tree/main/c-level-advisor --skill '*' -g -a claude-code

This installs the broader advisor pack, not only the Chief of Staff folder. See the pack’s own documentation and skill instructions.

Give it context first: what you sell, who buys it, the decision deadline, available resources, and evidence you already have.

✦ Ready to use

/chief-of-staff I run a small content business selling digital guides. I have 8 hours a week and need to choose between launching a new guide or improving an existing offer. Ask for missing business context first. Compare marketing, operations, and revenue perspectives. Show assumptions, disagreements, and at most five next steps with suggested owners and dates. Leave the final decision to me.

Check the result: Does it use your actual numbers? Are proposed actions practical within your available time? AI advisor roles provide simulated perspectives; they do not bring independent human expertise.

Anatomy: explore a concept visually

Best for: understanding a mechanism or technical idea through an illustration you can interact with.

Anatomy creates detailed isometric figures using SVG, with optional WebGL and 3D effects. Its output can be an HTML page or web component. Browse the author’s examples to see the intended style.

npx skills add wheresryan22/anatomy -g -a claude-code
✦ Ready to use

/anatomy Explain how a mechanical clock keeps time, interactive. Include controls I can explore and plain-language labels. Deliver a standalone HTML page and explain how to open it.

Name the idea you want explained and include “interactive” when you want controls. Start with a modest example before requesting a large 3D scene.

Check the result: Open the HTML file in your browser. Try every control, read the labels, and verify that the explanation matches a reliable source. The skill creates explanatory visuals; it does not guarantee that every depiction or calculation is correct.

Chapter 051 min read

Teach: build a learning workspace

Best for: learning a topic across several sessions, with something useful to return to.

Teach keeps lessons, reference sheets, and learning records in your work folder. The skill is intended to be invoked manually.

npx skills add mattpocock/skills --skill teach -g -a claude-code

Open Claude Code in a dedicated learning folder, then try:

✦ Ready to use

/teach Teach me email marketing for my digital-product business. I am a beginner with 20 minutes a day. Start by asking about my goal and current knowledge. Build short lessons, practice exercises, and a printable cheat sheet. Keep learning records in this folder and use reputable sources.

On a later visit, open the same folder and ask:

✦ Ready to use

/teach Continue my email-marketing lessons. Review the learning records, give me a short recall exercise, then choose the next lesson based on my answer.

Check the result: Look for lessons and reference materials in your work folder. Read the cited primary sources when learning factual material. The records help preserve continuity across conversations; they do not certify mastery.

Chapter 061 min read

Marketing Psychology: improve your message

Best for: connecting a marketing change to a clear hypothesis about how buyers decide.

This skill applies behavioral principles and mental models to messaging and marketing decisions. Give it your audience, offer, price, and existing copy so it can respond to a real situation.

npx skills add coreyhaines31/marketingskills --skill marketing-psychology -g -a claude-code
✦ Ready to use

/marketing-psychology Review this landing-page copy for my beginner AI guide: [paste copy]. Audience: [describe]. Price: [amount]. Identify three relevant psychology principles. For each, explain the issue, suggest a rewrite, and propose a measurable test. Use only real evidence and genuine customer proof. Keep the tone clear and helpful.

Check the result: Keep claims accurate and offers understandable. Treat the suggested principles as testable hypotheses. Choose a relevant measure, such as qualified signups or purchases, and compare results before adopting a change.

Chapter 072 min read

Last 30 Days: research recent conversations

Best for: finding timely questions and content angles within a defined subject.

npx skills add mvanhorn/last30days-skill --skill last30days -g -a claude-code

The current skill runtime requires Python 3.12 or newer. Its first-run setup guides you through optional source access. Read the configuration guide for your installed version.

Source What to expect
Reddit and Hacker News Public paths are available without source API keys, subject to access and rate limits.
YouTube Install yt-dlp for the public search/transcript path. Optional backends can add coverage.
X Configure a supported authenticated source through setup. It is not guaranteed to work immediately after installation.
Other sources Depend on the installed version, tools, credentials, and enabled options.

Optional services can charge for usage. Choose the source access you need during setup.

✦ Ready to use

/last30days Research what beginner creators have been asking about AI-assisted video editing in the last 30 days. Use available Reddit, X, and YouTube sources. Include dated source links, repeated questions, and five original content angles. State which platforms were searched successfully and which were unavailable.

Check the result: Open the cited posts, check dates, and distinguish repeated evidence from one popular opinion. Missing source access limits the research; it does not establish that nobody discussed the topic.

Chapter 081 min read

Using Claude on the web

Claude’s web skill upload is a separate route from the terminal commands above. In Claude, enable code execution and file creation, then go to Customize → Skills and use the upload option. Menus and organization controls can vary. See Anthropic’s current instructions.

For a custom upload, use a ZIP containing the complete skill folder, including SKILL.md and any supporting files. Downloading a repository ZIP is not the same as preparing an individual skill ZIP.

Last 30 Days provides a web-specific package: download the latest last30days.skill and follow the author’s web setup. Marketing Skills also documents web-target ZIP releases.

Uploading instructions does not install local software, configure credentials, or bring along companion skills. Anatomy’s local browser-checking tools and Chief of Staff’s broader advisor ecosystem need additional consideration. Use the Claude Code walkthrough in this guide for the documented local workflows.

Chapter 092 min read

Quick fixes and your first useful result

If this happens… Try this
npx is not recognized Install Node.js with npm, reopen the terminal, and repeat the version checks.
The skill does not appear Confirm you selected Claude Code, open a fresh session, and check the skill’s folder contains SKILL.md.
The wrong skill runs Check for duplicate installations and similarly named skills.
Chief of Staff mentions missing advisors Install the C-level pack described in its chapter.
Teach starts a new course Open the original learning folder so it can read the saved records.
Last 30 Days misses X or YouTube Check the runtime and source setup; ask it to report source health.

Your first goal is one usable result: a decision brief, an interactive explainer, a lesson, a better draft, or a sourced research note. Supply your real context, review the output, and save the parts that help.

Suggested starting point: Try Teach for a learning goal or Marketing Psychology for a draft you already have. Add the other skills when their workflows fit your work.
