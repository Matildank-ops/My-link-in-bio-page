# Illustrated guide covers

Ten original illustrations created with the built-in image generation tool on October 11, 2026. Each has 480, 960, and 1440 pixel WebP versions, named `<theme>-<width>.webp` in this directory. The original generated PNGs remain in the local generated-images folder; the website uses these optimized assets.

The homepage features, all 28 guide cards, two collection cards, and guide opening sections use these images. Related guides share thematic artwork. `manifest.json` records the URL-to-artwork mapping. Text and working URLs are retained. `../content-covers.css` controls image layouts and the lighter cover typography.
